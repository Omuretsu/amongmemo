# Among Memo

AirShip（10〜13人）向けの、Among Usプレイ中に使うローカル記録ツールです。Node.jsのローカルサーバーがプレイヤー情報とゲームログをGit管理外の`private/`へ保存します。

## 起動方法

Finderで`start.command`をダブルクリックします。ローカルサーバーの準備後、Safariで次のURLが開きます。

```text
http://127.0.0.1:3210
```

初回にmacOSから確認された場合は、`start.command`を右クリックして「開く」を選択してください。終了する場合は、起動したターミナルで`Control+C`を押します。

アプリ更新後に「旧サーバー・再起動が必要」と表示された場合は、以前の起動ターミナルで`Control+C`を押し、`start.command`をもう一度実行してください。画面だけを再読み込みしても、起動中のNodeプロセスは更新されません。

ターミナルから起動する場合：

```sh
node server.js
```

## 使い方

1. **メンバー管理**で普段のメンバーを登録します。登録時点でNodeサーバーへ保存されます。
2. その日の最初に参加者とホストをボタンで選びます。この画面から新しいプレイヤーも登録できます。自分は設定ファイルの名前で常時参加します。
3. 参加者の確定後、今回のルールと自分の役職を入力してゲームを開始します。
4. 部屋ボタンまたはショートカットで移動経路を記録します。
5. 会議時に通報・死亡・視認・キル不可能者を入力します。
6. **ゲームを終了**を押すとゲームログが保存され、終了するか次のゲームへ進むかを選べます。
7. 続ける場合は、前の参加者を引き継いだ一覧から退出者と新規参加者を変更します。ホストはゲームごとに選び直せます。

マップ上の全エリアにショートカットがあります。`⇧`表示はShiftキーとの同時押しです。
画面右上の **ショートカット ON/OFF** で、部屋・妨害・会議ボタン・死体通報・Backspaceを含むキー操作を一括で切り替えられます。設定は再読み込み後も保持されます。

- 妨害の番号は `1`：停電、`2`：コミュニケーション、`3`：リアクター
- `1` / `2` / `3`：対応する妨害を自分が修理したと記録
- `Shift+1` / `Shift+2` / `Shift+3`：対応する妨害が発生したと記録
- `Command+Shift+1` / `Command+Shift+2` / `Command+Shift+3`：対応する妨害を他者が修理したと記録
- `4`：自分が会議ボタンを押したと経路に記録（2回目はエラー）
- `Shift+4`：他者が会議ボタンを押したと経路に記録
- `5`：自分が死体を通報したと経路に記録
- `Shift+5`：他者が死体を通報したと経路に記録

保存に失敗した場合、ゲームデータはブラウザのローカルストレージに残り、画面はリセットされません。

## 個人データ

自分の設定はGit管理外の`private/settings.json`へ保存します。

```json
{
  "version": 1,
  "self": {
    "id": "self-local",
    "name": "YOUR_NAME"
  }
}
```

プレイヤーとゲームログは次の場所へ自動保存されます。

```text
private/
├── settings.json
├── players/
│   └── PLAYER_ID.json
└── games/
    └── GAME_ID.json
```

`private/`全体が`.gitignore`に登録されており、GitHubにはアップロードされません。

## 保存時の動作

- 未保存のプレイヤー：新しいJSONを作成
- IDと内容が同じプレイヤー：変更なし
- IDが同じで内容が異なるプレイヤー：一時ファイルへ保存後、既存ファイルとアトミックに置換
- 名前が同じでIDが異なるプレイヤー：競合として保存を中止
- ゲームログ：ゲームIDごとに一度だけ保存

## セキュリティ

- サーバーは`127.0.0.1`だけで待ち受けます。
- `private/`はHTTPで配信しません。
- 書き込みAPIは起動ごとのランダムトークンと同一Originを検証します。
- CORSを許可せず、JSON以外の書き込みを拒否します。
- プレイヤーID・名前・リクエストサイズを検証します。
- プレイヤーID以外をファイルパスに使用しません。
- CSPなどのセキュリティヘッダーを付与します。
- 外部npmパッケージは使用しません。

