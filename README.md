# Among Memo

AirShip（10〜13人）向けの、Among Usプレイ中に使うローカル記録ツールです。

## 使い方

1. [index.html](index.html) をブラウザで開きます。
2. **メンバー管理**で普段のメンバーを登録します。プレイヤーごとの**JSON保存**で個別ファイルを書き出せます。
3. 新規ゲームを開始し、今回の参加者・自分・役職を選びます。
4. 部屋ボタンまたはショートカットで移動経路を記録し、会議時に通報・死亡・視認・キル不可能者を入力します。

マップ上の全エリアにショートカットがあります。ボタン右側の緑色のキーを押して移動先を追加でき、`⇧` 表示は Shift キーとの同時押しを示します。

- `1`：停電の修理を現在の経路へ追加
- `2`：コミュニケーションの修理を現在の経路へ追加
- `3`：リアクターの修理を現在の経路へ追加

自分が修理した場合、修理は移動経路と妨害修理ログの両方へ記録されます。

すべての試合とメンバー情報は、そのブラウザのローカルストレージに自動保存されます。別のブラウザや端末へ移す場合は、**JSON保存**でメンバーをエクスポートし、**JSON読込**で取り込んでください。複数のプレイヤーJSONをまとめて選択して読み込むこともできます。

## 個人データの管理

自分の設定は、Git管理外の `private/settings.js` に保存します。

```javascript
window.AMONG_MEMO_PRIVATE = {
  self: {
    id: 'self-local',
    name: 'YOUR_NAME'
  }
};
```

この設定がある場合、起動時に自分が自動選択され、参加メンバーから外せない状態になります。

SafariではWebページから任意のローカルフォルダへ直接書き込めません。画面からプレイヤーJSONを保存した後、ダウンロードされたファイルを手動で `private/players/` へ移してください。`private/settings.js`と`private/players/`は`.gitignore`に登録されているため、GitHubにはアップロードされません。

## メンバーJSON形式

個別プレイヤーファイル：

```json
{
  "version": 1,
  "player": { "id": "alice", "name": "Alice" }
}
```

全員をまとめたファイル：

```json
{
  "version": 1,
  "members": [
    { "id": "alice", "name": "Alice" },
    { "id": "bob", "name": "Bob" }
  ]
}
```

`id` がないJSONも読み込めます。その場合は自動でIDを作成します。

## ファイル構成

```text
amongmemo/
├── index.html          # 画面構造
├── css/
│   └── style.css       # 画面とマップのスタイル
├── js/
│   ├── map-data.js     # 部屋、座標、ショートカットの定義
│   └── app.js          # 記録、保存、会議などの処理
└── private/            # Git管理外の個人データ
    ├── settings.js     # 自分の設定
    └── players/        # プレイヤーごとのJSON
```

外部ライブラリやビルド処理は使用していません。フォルダ構成を保ったまま `index.html` を開けば利用できます。
