# Among Memo

AirShip（10〜13人）向けの、Among Usプレイ中に使うローカル記録ツールです。

## 使い方

1. [index.html](index.html) をブラウザで開きます。
2. **メンバー管理**で普段のメンバーを登録します。
3. 新規ゲームを開始し、今回の参加者・自分・役職を選びます。
4. 部屋ボタンまたはショートカットで移動経路を記録し、会議時に通報・死亡・視認・キル不可能者を入力します。

マップ上の全エリアにショートカットがあります。ボタン右側の緑色のキーを押して移動先を追加でき、`⇧` 表示は Shift キーとの同時押しを示します。

- `1`：停電の修理を現在の経路へ追加
- `2`：コミュニケーションの修理を現在の経路へ追加
- `3`：リアクターの修理を現在の経路へ追加

自分が修理した場合、修理は移動経路と妨害修理ログの両方へ記録されます。

すべての試合とメンバー情報は、そのブラウザのローカルストレージに自動保存されます。別のブラウザや端末へ移す場合は、**JSON保存**でメンバーをエクスポートし、**JSON読込**で取り込んでください。

## メンバーJSON形式

```json
{
  "members": [
    { "id": "alice", "name": "Alice" },
    { "id": "bob", "name": "Bob" }
  ]
}
```

`id` がないJSONも読み込めます。その場合は自動でIDを作成します。
